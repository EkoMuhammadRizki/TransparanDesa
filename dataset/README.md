# Dataset TransparanDesa

Direktori ini digunakan untuk menyimpan seluruh dataset yang diperlukan untuk pengembangan dan evaluasi AI Pipeline serta Anomaly Detection Engine.

## Struktur Direktori:

- **`pdf_apbdes/`**: Letakkan semua dokumen PDF APBDes (hasil ekspor Siskeudes, perdes APBDes, laporan realisasi, dsb).
- **`benchmark_data/`**: Letakkan data tabular agregat (CSV/Excel/JSON) seperti alokasi dana desa per kabupaten/desa, data Indeks Desa Membangun (IDM), dan statistik belanja desa nasional.
- **`ground_truth/`**: Hasil ekstraksi JSON acuan yang telah diverifikasi secara manual untuk pengujian akurasi AI.
